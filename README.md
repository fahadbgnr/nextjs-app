# NextjsApp

[Live Demo](https://nextjs-app-seven-phi.vercel.app/)

## Project Overview

NextjsApp is a modern web application built with **Next.js** and **Tailwind CSS**. It showcases a dynamic product/service listing with responsive design, authentication, and interactive UI components.

This project demonstrates:

- Dynamic product/service rendering
- Responsive layouts for all screen sizes
- Navigation with Next.js `Link` and `usePathname`
- User authentication with NextAuth
- Modern styling using Tailwind CSS
- Server-side or static data fetching
- Clean and reusable React components

---

## Features

- **Home Page:** Landing page with project introduction.
- **Product/Services Page:** Displays a list of services with images, description, facilities, and pricing.
- **Authentication:** Login/Logout functionality using NextAuth.
- **Dashboard:** Conditional rendering based on user session.
- **Responsive Design:** Works perfectly on mobile, tablet, and desktop screens.
- **Footer:** Useful links, company info, legal information with consistent styling.
- **Image Optimization:** Remote images handled via Next.js `Image` component.

---

## Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS
- **Authentication:** NextAuth.js
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Image Handling:** Next.js `Image` component
